# EnglishGate Learning Ladder Standard

## Purpose

Every EnglishGate workbook skill must move the learner from supported understanding to independent use through the same five visible stages:

1. **Recognize** — I can recognize the target language or idea.
2. **Build** — I can build a correct response with support.
3. **Correct** — I can notice and fix mistakes.
4. **Apply** — I can use the skill in a realistic context.
5. **Perform** — I can use the skill independently.

The ladder sits **inside the learner's assigned CEFR level**. It does not replace A1, A2, B1, B2, C1 or C2.

## Student experience

- Each workbook skill shows the full five-step ladder before the activity.
- The current stage is visible, completed stages are marked as reached, and later stages remain visible.
- Questions are ordered from more supported to less supported work.
- The result screen tells the learner the highest consecutive stage reached and the next goal.
- A new attempt can improve the learner's ladder standing without deleting earlier scores or completion evidence.

## Skill interpretation

### Vocabulary
Recognize meaning → build/retrieve phrases → repair inaccurate language → apply in context → retrieve/use independently.

### Listening & Reading
Recognize main message → build detailed understanding → correct misleading interpretations → apply inference/context → respond independently from source evidence.

### Grammar
Recognize the pattern → build accurate forms → correct errors → apply in context → produce the correct form with less support. The final grammar items remove answer choices and require typed answers while remaining auto-graded.

### Writing
Recognize sentence structure → build/combine ideas → correct errors → apply organization → perform through one authentic real-life writing response.

## Data safety

The ladder is additive. Existing student accounts, classes, enrollments, attempts, completion records, writing, certificates and prior scores must remain unchanged. Ladder standing is stored only as an additional attempt tag on new attempts.
